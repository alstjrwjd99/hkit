# 데이터 탐색과 의사결정 인계

## 호출과 위임

오케스트레이터가 데이터 가설 검증, 품질이 구현·정확도에 미치는 영향, KPI·기준선 비교 중 하나가 필요한지 확인해 호출한다. 해당 사항이 없는 CRUD 과제는 생략 사유를 남긴다. 필요한 데이터가 없으면 영향을 받는 AC와 필요한 입력을 명시한다.

소규모 구조 파악과 단일 가설은 메인 세션에서 실행한다. 복잡한 통계, 여러 가설·파일 비교, 큰 데이터의 반복 처리는 병렬 실행이 허용되면 `eda` 서브에이전트에게 범위를 한정해 맡긴다. 전달할 것은 PRD 리비전·R/AC·검증할 가설·KPI 산식과 대상·입력 경로·시간/자원 한도·쓰기 경로다. 공통 PRD·계약·검증표는 부모가 관리하고, EDA는 배정된 분석·보고서·계약 초안 경로에만 쓴다. 중간 표와 원자료는 로컬 파일에 두고 부모에게 결론·근거 경로·영향·미검증 사항을 요약한다.

## 품질과 기준선

1. 원본의 형식·인코딩·관측 단위·기간·키·조인 관계를 확인하고 보존한다. 아래 스크립트는 Python 3.11 이상과 표준 라이브러리로 실행한다.
   ```sh
   python3 .agents/skills/eda/scripts/profile_csv.py data/input.csv --encoding cp949 --key route_id,stop_id --date service_date=%Y-%m-%d --prd-revision P1 --contract-out docs/data-contract.json > docs/data-profile.json
   ```
   옵션은 실제 파일에 맞춰 선택한다. 기본 인코딩은 UTF-8(BOM 포함), TSV 구분자는 탭이다. 인코딩 오류를 파일 내용 오류와 구별하고 확인한 인코딩을 명시해 재실행한다. 명령의 종료 코드를 확인한 뒤 결과 파일에서 필요한 집계만 읽는다.
2. 프로파일에는 기존 행·중복 집계와 열별 타입 추정, 결측률, 숫자 범위, 날짜 유효성, 단일·지정 복합키 후보가 담긴다. 결측은 빈 문자열·공백, 키 비교는 원문 값 기준이다. 분모는 열 수가 맞는 행이다. ISO 모양의 날짜를 자동 검사하며 다른 형식은 `--date COLUMN=FORMAT`으로 지정한다. 숫자 범위는 정밀도 보존용 문자열이다. 선행 0이 있는 식별자는 문자열로 보존한다.
3. 큰 파일의 초기 탐색에는 `--max-rows N`으로 읽을 레코드 수를 제한하고 `complete_scan`을 확인한다. 고유값·중복 집계 메모리는 서로 다른 값과 행 수에 비례한다. 전수 검사가 필요하면 자원 한도에 맞는 분할 집계를 과제별 분석 코드로 작성한다. 표본에서 관찰한 고유성·범위를 전체 모집단의 제약으로 확정하지 않는다.
4. PRD의 핵심 가설과 KPI 기준선을 과제별 분석 스크립트로 계산한다. 입력 식별값·포함/제외 조건·분모·산식을 고정하고 같은 표본의 대안 및 독립 집계와 대조한다. 이상치는 영향과 원인을 조사하고 처리 후보를 제안한다. 제거·대체는 요구나 확인된 처리 규칙을 근거로 한다.

## PRD와 BE로 반환

- `docs/data-report.md`에는 입력·PRD 리비전, 재실행 명령과 실제 결과, 가설별 판정, 반례·한계를 기록한다. 해당 R/AC마다 요구 변경 제안·새 검증 사례·추가 입력 중 필요한 조치를 명시한다.
- `docs/data-contract.json`은 [데이터 계약 규격](references/data-contract.md)을 따른다. 스크립트가 만드는 초안에는 관찰값과 빈 제약 목록이 들어 있다. 부모가 요구·검증 근거로 제약을 확정하고, BE가 해당 리비전의 입력 검증과 제약 테스트로 연결한다.
- PRD 담당이 결과를 수용·수정·보류하면 EDA가 변경된 가설·산식·대상에 필요한 분석만 다시 실행한다. 문제 정의·주 KPI·범위가 달라지면 Explain으로 실제 결정이 필요한 쟁점을 전달한다.

데이터 구조·품질과 필요한 KPI 기준선을 재현하고, 결과가 관련 R/AC의 PRD 결정과 BE 시나리오에 연결될 때 완료한다. 부모는 핵심 명령을 재실행하고 현재 PRD·입력·데이터 계약 리비전과 일치하는지 확인한다. 재현하지 못한 결과와 아직 인계되지 않은 제약은 미검증으로 남긴다.
