# 사람의 판단을 돕는 설명

1. 지금 확인할 수 있는 사실부터 조사한다. 비교 가능한 대안은 같은 입력·기준선으로 실험하고 근거가 있는 보고서나 검증 행을 가리킨다. 아직 측정할 수 없으면 이유와 영향을 밝힌다.
2. 사람이 선택해야 할 때는 영향을 받는 사용자, 대안별 이득과 손실, 권하는 안과 이유를 짧게 설명한 뒤 결정 하나를 묻는다. 가령 버스 노선이라면 같은 노선·시간대의 운행시간과 정류장 대기시간을 함께 비교하고, 두 지표가 충돌할 때 어느 쪽을 우선할지 묻는다. 임의의 가중치 승인을 먼저 요청하지 않는다.
3. `docs/decision-log.md`에 관련 R/AC, 선택지와 근거, 상태(제안/결정), 실제 결정 주체·답변 및 후속 변경을 남긴다. AI의 권고와 사용자가 확정한 선택을 구별한다. 초기 문제 정의, 주 KPI, 범위 변경은 확인될 때까지 기존 합의를 유지한다.
4. 제출 전에는 사용자가 자신의 말로 설명할 수 있도록 핵심 흐름, 중요한 결정 하나와 관찰값, 남은 한계를 근거 문서와 연결한다. 제출 확정 뒤에는 키트의 후속 서술형 제한을 따른다.
