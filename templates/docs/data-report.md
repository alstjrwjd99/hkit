# 데이터 분석 보고서

## 입력과 재현
| 입력 경로·SHA-256·인코딩 | PRD 리비전·가설 ID / 관측 단위·키·범위 | 분석 스크립트와 실행 명령 | 전수·표본·포함/제외 조건 |
|---|---|---|---|

## 품질
| 점검 항목 | 실제 관찰값 / 분모 | 처리 방법 | 영향을 받는 요구·KPI |
|---|---|---|---|

## 가설과 기준선
| 요구 ID / 가설 | 지표와 비교 조건 | 기준선 | 대안 결과 | 반례·한계 |
|---|---|---|---|---|

측정할 수 없는 항목은 원인과 필요한 입력을 적는다. 결과가 범위나 KPI 선택을 바꾸면 [PRD](prd.md)와 [결정 로그](decision-log.md)에 연결한다.

## 의사결정과 구현으로 인계

| 가설 ID / 관련 R·AC | 재현 결과·한계 | PRD 변경 제안과 필요한 결정 | 데이터 계약 리비전·제약 ID | BE 정상·위반·경계 시나리오 | 부모의 수용·수정·보류 위치 |
|---|---|---|---|---|---|

기계가 읽는 관찰·제약은 실행 시 생성하는 data-contract.json에 둔다. 보고서는 해당 경로·리비전을 가리킨다. 재현하지 못한 결과와 아직 PRD·BE에 인계되지 않은 사항은 미검증으로 남긴다.
