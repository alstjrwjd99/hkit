# PRD

- PRD 리비전

## 문제와 범위
- 사용자와 현재 겪는 문제
- 핵심 흐름 (시작 조건 → 행동 → 사용자가 확인할 결과)
- 이번 과제의 필수 범위와 제외 범위

## 성공 지표
| 1차 KPI / 보조 지표 | 산식·단위·개선 방향 | 평가 대상·기간 | 기준선 근거 | 목표와 출처 |
|---|---|---|---|---|

데이터 제약과 측정 결과는 [데이터 보고서](data-report.md), 사람이 선택한 우선순위는 [결정 로그](decision-log.md)에 연결한다.

## 수용 기준
[SPEC](../SPEC.md)의 요구 ID에서 AC를 파생한다. 기존 명세에 상세 AC가 있으면 해당 위치를 참조한다.

| AC ID | 요구 ID | 시작 조건과 입력 | 사용자 행동 | 관찰할 기대 결과 | 검증 방법 |
|---|---|---|---|---|---|

## EDA 요청과 반환

가설 검증·품질 영향·KPI 비교가 필요한지와 실행 또는 생략 이유를 기록한다.

| 가설 ID / 관련 R·AC | PRD 리비전 | 검증할 주장·필요한 결정 | 입력·평가 대상·기간 | 산식·분모·비교 기준 |
|---|---|---|---|---|

| 가설 ID | EDA 근거 위치·입력 버전 | 확인한 제약과 요구·BE 테스트 변경 제안 | 수용 / 수정 / 보류와 이유 | 변경 리비전·재분석 조건 |
|---|---|---|---|---|
