# FE·BE 계약

- 상태 (초안 / 확정) · 버전 또는 기존 스키마 경로
- 연결할 AC와 사용자 동작
- FE 소유 경로 · BE 소유 경로 · 공유 파일 및 통합 담당
- EDA가 있으면 현재 PRD와 맞는 데이터 계약 경로·리비전 및 적용할 확정 제약 ID

| 메서드·경로 | 요청 필드·타입·필수 여부·단위 | 성공 상태·응답 타입 | 오류 조건·상태·본문 |
|---|---|---|---|

## 같은 입력으로 확인할 예
- 성공 요청과 응답
- 경계·실패 요청과 응답
- 누락, null, 빈 결과의 의미 및 필요한 상태 변화

오케스트레이터가 변경을 반영한 뒤 영향받는 양쪽에 새 계약 버전을 전달하고 해당 AC를 다시 검증한다.
